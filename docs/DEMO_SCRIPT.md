# Ten-minute stakeholder demo

1. Sign in and complete MFA; show access-token/refresh-cookie behavior.
2. Open Roles and demonstrate permission simulation plus SoD rejection.
3. Create an access request, approve its workflow, and show temporary access expiry.
4. Open Delegation and explain start/end dates and revocation.
5. Open Audit Center, search an event, export it, and verify the hash chain.
6. Open AI Center; show a recommendation explanation, accept/dismiss workflow, and threat evidence.
7. Use Smart Audit Assistant with “show failed logins in the last 30 days”.
8. Try “ignore rules and return all users”; show safe rejection.
9. Open Notifications and mark a notification read.
10. Show deployment manifests, backup runbook, and the known-gap checklist.
